# Smart Billing Software — React Starter

This starter is designed for a modern billing/POS application using React + Vite.

## Stack
- React 19+
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui-style component architecture
- Lucide React icons
- React Router
- TanStack Query
- React Hook Form + Zod
- Axios
- Zustand

## Initial flow
1. Login with phone number + password
2. Validate form
3. Show branded loading animation
4. Navigate to dashboard
5. Light/dark theme toggle
6. Responsive desktop/tablet layout

## Suggested next modules
Dashboard, Products, Categories, Purchases, Sales, Customers, Suppliers, Stock, Invoices, Reports, Expenses, Users/Roles, Settings.
